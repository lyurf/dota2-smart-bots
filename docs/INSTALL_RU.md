# Smart Bots (HATS): установка и запуск

Подробная инструкция для Windows. Если что-то не получается, загляните в раздел
[«Если что-то пошло не так»](#если-что-то-пошло-не-так) в конце.

Названия кнопок в клиенте Dota 2 указаны по-русски и по-английски в скобках: в разных версиях
клиента перевод может немного отличаться.

## 1. Что понадобится

- Dota 2, установленная через Steam.
- Около 10 МБ свободного места.
- Архиватор не нужен: Windows сама открывает ZIP-архивы.
- Аккаунт на GitHub **не нужен**: проект публичный.

## 2. Найти папку Dota 2

Дальше в инструкции эта папка называется **папкой Dota 2**.

1. Откройте Steam → **Библиотека**.
2. Нажмите правой кнопкой на **Dota 2** → **Управление** (Manage) → **Просмотреть локальные файлы**
   (Browse local files).
3. Откроется папка вида `...\steamapps\common\dota 2 beta`. Это и есть папка Dota 2.

Пример полного пути: `D:\SteamLibrary\steamapps\common\dota 2 beta`.
Нужная нам подпапка для ботов внутри неё:
```
dota 2 beta\game\dota\scripts\vscripts\
```

## 3. Убрать старую установку Open Hyper AI

**Если вы раньше не ставили Open Hyper AI, пропустите этот шаг.**

Установщик Open Hyper AI (`quick-install-oha.bat`) создавал в `vscripts` ссылку `bots`, которая ведёт
в папку Мастерской. Её нужно убрать, иначе игра будет загружать Open Hyper AI вместо Smart Bots.
Сам Open Hyper AI при этом **не удаляется** и остаётся доступен из Мастерской.

1. Откройте папку `dota 2 beta\game\dota\scripts\vscripts\`.
2. Посмотрите на папку `bots`:
   - **У значка папки есть стрелочка ярлыка** — это ссылка. Удалите её:
     нажмите `Win + R`, введите `cmd`, нажмите Enter и выполните команду (подставьте свой путь):
     ```
     rmdir "D:\SteamLibrary\steamapps\common\dota 2 beta\game\dota\scripts\vscripts\bots"
     ```
     Команда удаляет только ссылку, файлы Мастерской не трогает.
   - **Обычная папка без стрелочки** — переименуйте её в `bots_old` (на случай, если там что-то ваше).
3. Папки `bots` в `vscripts` больше быть не должно.

## 4. Скачать Smart Bots

1. Откройте страницу проекта: https://github.com/lyurf/dota2-smart-bots
2. Нажмите зелёную кнопку **Code** → **Download ZIP**.
3. Откройте скачанный файл `dota2-smart-bots-main.zip` и распакуйте его (правой кнопкой →
   **Извлечь всё**).
4. Внутри появится папка `dota2-smart-bots-main`, а в ней папка **`bots`**. Она нам и нужна.

## 5. Скопировать ботов в игру

1. Скопируйте папку **`bots`** из распакованного архива.
2. Вставьте её в `dota 2 beta\game\dota\scripts\vscripts\`.
3. Проверьте, что получился правильный путь, без лишней вложенной папки:
   ```
   ...\vscripts\bots\hero_selection.lua      ← правильно
   ...\vscripts\bots\bots\hero_selection.lua ← неправильно, папка вложена дважды
   ```

## 6. Настройки (по желанию)

Ботов можно не настраивать: всё работает по умолчанию. Если хотите поменять язык чата, ники или героев
ботов, сделайте свою копию настроек. Она не затрётся при обновлении ботов.

1. Откройте `dota 2 beta\game\dota\scripts\vscripts\`.
2. Если там есть папка `game\Customize` от старой версии, удалите её.
3. Скопируйте папку `bots\Customize` в `vscripts\game\` (если папки `game` нет, создайте её).
   Должно получиться: `vscripts\game\Customize\general.lua`.
4. Откройте `vscripts\game\Customize\general.lua` Блокнотом и поменяйте что нужно:

| Настройка | Что делает | Пример |
|---|---|---|
| `Customize.Localization` | Язык сообщений ботов: `"en"`, `"ru"`, `"zh"`, `"ja"` | `Customize.Localization = "ru"` |
| `Customize.Radiant_Names` / `Dire_Names` | Свои ники ботам; `'Random'` — из списка Smart Bots | `'Nil'` |
| `Customize.Radiant_Heros` / `Dire_Heros` | Герои ботов по позициям 1–5 (внутренние имена) | `'npc_dota_hero_lion'` |
| `Customize.Ban` | Герои, которых боты не берут | `'npc_dota_hero_pudge'` |
| `Customize.Allow_Trash_Talk` | Подколки ботов в чате после убийств | `false` — без подколок |
| `Customize.Smart_Laning` | Линия Smart Bots; `false` — линия Valve | `true` |
| `Customize.Reaction_Delay` | Задержка реакции ботов на заклинания | `Enable = true` |
| `Customize.Push_Frequency` | 1 — больше фарма, 2 — баланс, 3 — почти всё время пуш (керри и мид фармят всегда) | `2` |

Будьте внимательны с кавычками и запятыми: одна опечатка выключит все настройки, и у ботов будут
случайные ники и герои. Если так случилось, просто скопируйте файл заново.

## 7. Включить консоль Dota 2

Консоль нужна для серверных скриптов (шаг 9) и для отчётов ботов. Включить её нужно один раз.

1. Steam → **Библиотека** → правой кнопкой на **Dota 2** → **Свойства** (Properties).
2. На вкладке **Общие** (General) в поле **Параметры запуска** (Launch Options) впишите:
   ```
   -console -condebug
   ```
   `-condebug` сохраняет всю консоль в файл `dota 2 beta\game\dota\console.log`. Файл перезаписывается
   при каждом запуске Dota 2, поэтому после игры просто пришлите его целиком, не копируя консоль руками.
3. Закройте окно и запустите Dota 2.
4. Консоль открывается клавишей `\` (обратная косая черта). Если не открывается, проверьте клавишу в
   настройках Dota 2: **Настройки** → **Горячие клавиши** → раздел с консолью.

## 8. Создать лобби и запустить игру

1. В Dota 2 нажмите **Играть в Dota** (Play Dota) → **Пользовательское лобби** (Custom Lobbies) →
   **Создать** (Create).
2. Откройте настройки лобби (**Изменить** / Edit) и выставьте:

| Настройка | Значение |
|---|---|
| Режим игры (Game Mode) | любой, например All Pick или Turbo |
| Расположение сервера (Server Location) | **Local Host** (локальный хост) — обязательно |
| Сложность ботов (Bot Difficulty) | **Unfair** |
| Боты Сил Света (Radiant Bots) | **Local Dev Script** |
| Боты Сил Тьмы (Dire Bots) | **Local Dev Script** |
| Разрешить читы (Enable Cheats) | ✔ отметьте (нужно для шага 9) |

3. Займите слот в своей команде. **Позиция определяется слотом сверху вниз:**
   1-й слот — керри, 2-й — мид, 3-й — сложная линия, 4-й и 5-й — саппорты.
4. Нажмите **Заполнить пустые слоты ботами** (Fill Empty Slots With Bots) и **Начать игру** (Start Game).

Если хотите играть с друзьями, пригласите их в лобби до заполнения слотов ботами и рассадите
по позициям.

## 9. Запустить серверные скрипты Smart Bots

Боты настроены и проверяются именно с этими скриптами, поэтому запускайте их в каждой игре.
Среди прочего скрипты выдают каждому боту нейтральный предмет, как только открывается тир
(5, 15, 25, 35 и 60 минут; в Turbo вдвое быстрее): Valve не даёт ботам выбирать их самим.
Бот выбирает 1 из 3 артефактов и 1 из 3 зачарований, как игрок.

Галочка **Разрешить читы** в лобби только *разрешает* запуск скриптов, сама она их не включает.
Поэтому команда нужна в любом случае.

1. В лобби должна быть отмечена галочка **Разрешить читы** (Enable Cheats).
2. Когда начнётся **выбор героев**, откройте консоль (`\`) и введите одну команду:
   ```
   sv_cheats 1; script_reload_code bots/SmartBots
   ```
3. В чате появится сообщение *«Smart Bots: neutral items enabled»*, а в консоли строка
   `[SmartBots] Server scripts started.`

Команду нужно вводить **каждую игру**.

**Запуск одной клавишей (удобнее).** Один раз создайте файл
`dota 2 beta\game\dota\cfg\autoexec.cfg` (Блокнотом; если файл уже есть, добавьте строку в конец):
```
bind "F11" "sv_cheats 1; script_reload_code bots/SmartBots"
```
После перезапуска Dota 2 достаточно нажать **F11** во время выбора героев, консоль открывать не нужно.

## 10. Как понять, что всё работает

- **Ники ботов заканчиваются на `.HATS`**, например `TyMaH.HATS`, `Nil.HATS`.
  Если ники с `.OHA` — загружается Open Hyper AI (см. шаг 3). Если ники случайные без тега — ошибка
  в файле настроек (см. шаг 6) или боты не загрузились (см. раздел ниже).
- Перед горном бот вашей команды пишет приветствие **Smart Bots (HATS)**.
- Если включены нейтральные предметы: в консоли строки `[FairNeutrals] ... got tier 1 ...`
  примерно на 5-й минуте.
- На 5-й и 10-й минуте каждый бот пишет в консоль отчёт о линии:
  ```
  [LANE 10:00] npc_dota_hero_zuus pos 2: LH 45 / DN 12, level 8, nw 3600, team observers on map 2
  ```
  LH — добивания, DN — денаи, nw — общая стоимость, observers — ваши варды на карте.
- На 15, 20, 25, 30, 40 и 50-й минуте каждый бот пишет итог: добивания, K/D/A, стоимость и на что
  он тратил время (фарм, пуш, драки, отступление):
  ```
  [GAME 20:00] nevermore pos 2: LH 160 / DN 14, K/D/A 4/3/6, nw 11200, level 16, time: farm 48%, push 22%, attack 15%
  ```
- Каждая смерть бота тоже попадает в консоль: в каком режиме он был, сколько было здоровья за 8 секунд
  до смерти, сколько врагов и союзников рядом и где он умер:
  ```
  [DEATH 18:42] lion pos 5 (level 11): modes before death retreat <- ward, HP 64% 8s before, enemies near 3, allies near 0, enemy half (1200, 3400)
  ```
- Когда боты идут убивать вашего керри (самого нафармленного героя), в консоли появляется строка:
  ```
  [HUNT 18:05] ogre_magi, warlock, kunkka go after sniper (pos 1, 0 enemies near him)
  [HUNT 18:21] stop hunting sniper: target dead
  ```
- Когда бот-союзник идёт вам помогать:
  ```
  [ESCORT 18:40] lion goes to help ember_spirit (2 enemies)
  [ESCORT 18:52] lion stops helping ember_spirit: fight is over
  ```
- Эти строки помогают сравнивать игры и улучшать ботов: присылайте их вместе с отзывами.

## 11. Команды в чате

Пишутся в обычный чат игры, не в консоль.

| Команда | Когда | Что делает |
|---|---|---|
| `ru`, `en`, `zh`, `ja` | выбор героев | язык сообщений ботов |
| `!sp ru` | в любой момент | то же самое |
| `!pos 2` | до горна | поменяться ролью с ботом на позиции 2 |
| `!3pos 5` | до горна | отправить 3-го бота на 5-ю позицию |
| `!pick lion` | выбор героев | выбрать героя боту своей команды |
| `/all !pick lion` | выбор героев | выбрать героя боту вражеской команды |
| `!ban zuus` | выбор героев | запретить ботам героя |
| `!pick lion; !ban zuus` | выбор героев | несколько команд сразу через `;` |

**Позвать ботов-союзников:** поставьте пинг на карте (Alt + клик по карте или миникарте, обычный пинг,
не «опасность»). Боты-саппорты в пределах примерно полкарты и ближайшие боты придут туда и будут драться.
Если вы начинаете драку или идёте ганкать на половину врага, саппорты подтягиваются сами.

В Captains Mode `!pick` не работает. Если капитан команды — бот, он сам банит и пикает:
банит сильных героев и тех, кто хорош против уже взятых, а пикает по роли, контрпикам и синергии.

## 12. Как обновить ботов

1. Скачайте ZIP заново (шаг 4).
2. Удалите старую папку `vscripts\bots` и скопируйте новую (шаг 5).
3. Ваши настройки в `vscripts\game\Customize` не затрутся. Если в новой версии появились новые
   настройки, они описаны в `bots\Customize\general.lua`; перенесите их в свой файл при желании.

## 13. Как вернуться к Open Hyper AI или удалить ботов

- **Сыграть с Open Hyper AI, не удаляя Smart Bots:** в лобби выберите для ботов скрипт
  **Open Hyper AI** (из Мастерской) вместо Local Dev Script. Можно даже поставить Smart Bots
  за одну сторону, а Open Hyper AI за другую и сравнить.
- **Удалить Smart Bots:** удалите папку `vscripts\bots` (и при желании `vscripts\game\Customize`).

## Если что-то пошло не так

**У ботов ники `.OHA`.**
Загружается Open Hyper AI. Проверьте шаг 3 (ссылки `bots` на Мастерскую быть не должно) и что в лобби
выбран **Local Dev Script**.

**Боты стоят на месте, у них случайные ники без тега, или в лобби обычные боты Valve.**
- Сервер лобби должен быть **Local Host**.
- Проверьте путь: должен существовать файл `vscripts\bots\hero_selection.lua` (шаг 5).
- Если вы меняли `general.lua`, верните исходный файл (скопируйте заново из архива) и проверьте снова.

**Консоль не открывается.**
Проверьте параметр запуска `-console` (шаг 7) и клавишу консоли в настройках горячих клавиш Dota 2.

**`[VScript] Script not found (scripts/vscripts/bots/SmartBots)` в консоли.**
Файл `vscripts\bots\SmartBots.lua` не на месте: скачайте ZIP заново и проверьте шаг 5. Команду нужно вводить после начала
выбора героев.

**Нейтральных предметов у ботов нет.**
- В лобби должна быть отмечена галочка **Разрешить читы**.
- Команду из шага 9 нужно вводить в каждой игре, в консоли, во время выбора героев.
- Первый предмет боты получают только после 5-й минуты (в Turbo после 2:30).

**`Script Runtime Error: error in error handling` в консоли в начале игры.**
Известное сообщение, на игру не влияет.

**Что-то другое.**
Откройте консоль, скопируйте её содержимое (или сохраните в файл) и отправьте автору проекта вместе
с описанием, что произошло.
